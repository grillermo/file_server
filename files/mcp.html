file_server MCP

Lets Claude Code upload local files to files.chiq.me. Log in once per machine with a code from Slack #otp; the token never expires.

New machine

git clone git@github.com:grillermo/agents-configs.git ~/c/agents-configs
~/c/agents-configs/install.sh

Already have agents-configs

cd ~/c/agents-configs && git pull && ./install.sh

Without install.sh

claude mcp add --scope user file_server -- ruby ~/c/agents-configs/mcp/file_server/server.rb

Log in and upload

  1. In Claude Code: log in to file_server
  2. Paste the 6-digit code posted to Slack #otp.
  3. upload ~/path/to/file — Claude replies with the URL.

Needs Ruby 3. Point at another server with FILE_SERVER_URL; at home it uploads straight to FILE_SERVER_LAN_URL (default http://192.168.1.1:33333), which has no 25 MB cap. The token lives in ~/.config/file_server/token.

Revoke a machine (on the server)

bin/tokens list
bin/tokens revoke <hostname>
